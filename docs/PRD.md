# 个人技术博客 — PRD

## 产品概述

一个面向国内开发者的个人技术博客，风格参考 yudesk.dev。内容涵盖编程语言学习、AI 技术探索、Agent 工具使用经验。支持在线编辑与外部 MD 文件导入，提供全文搜索与标签筛选，通过 GitHub 账号进行评论互动。

## 目标用户

| 角色 | 描述 |
|---|---|
| 博主（我） | 写技术文章，管理内容，后期可能构建个人品牌 |
| 读者 | 国内开发者，阅读技术文章、搜索内容、参与评论 |

## 功能范围

### P0 — MVP 必须实现

| 功能 | 说明 |
|---|---|
| 文章管理 CRUD | 创建、编辑、删除、发布/草稿切换 |
| Markdown 在线编辑 | ByteMD 编辑器，GitHub Flavored Markdown，实时预览 |
| MD 文件导入 | 支持 `.md` 文件上传，自动解析 frontmatter（标题、日期、标签） |
| MDX 渲染 | 文章详情页支持 MDX（可嵌入 React 组件） |
| 文章列表页 | 标签筛选 + 分页，按发布时间倒序 |
| 文章详情页 | 正文 + 目录导航（TOC）+ 评论区 |
| 暗色模式 | 跟随系统 + 手动切换，next-themes 实现 |
| 管理员认证 | Basic Auth（环境变量密码），保护 `/admin` 路由 |
| 本地图片上传 | 编辑器中上传图片，存储本地文件系统 |
| 响应式布局 | 桌面 + 移动端适配 |

### P1 — 有精力就做

| 功能 | 说明 |
|---|---|
| 全文搜索 | Pagefind 构建时生成索引，纯静态搜索 |
| RSS Feed | 生成 `/rss.xml`，支持阅读器订阅 |
| SEO 优化 | 动态 `generateMetadata`，OG 标签，结构化数据 |
| 代码块增强 | 行号、高亮行、复制按钮 |
| 标签云/归档页 | 按年份或标签聚合展示 |
| 首页文章卡片优化 | 封面图、摘要、阅读时间估算 |

### P2 — 后期迭代

| 功能 | 说明 |
|---|---|
| 知识地图 | AI 生成，卡通美术风格，可交互 SVG/Canvas |
| 评论系统升级 | 从 Giscus 迁移到 Gitalk/自建评论 |
| NextAuth + GitHub OAuth | 替代 Basic Auth，支持多管理员 |
| 图床 OSS | 阿里云 OSS / 腾讯云 COS |
| CI/CD 自动部署 | GitHub Actions → 阿里云 ECS |
| 访问统计 | 文章阅读量、访问来源 |
| 友链/导航页 | 支持添加友情链接 |
| 订阅/Newsletter | 邮件通知新文章 |

## 非功能需求

| 类别 | 要求 |
|---|---|
| 首屏加载 | < 2s（Lighthouse 90+） |
| 数据库 | SQLite，单文件，零运维 |
| 部署 | 前期本地，后期阿里云/腾讯云 Docker |
| SEO | 文章页 SSR，搜索引擎友好 |
| 安全性 | 管理后台鉴权，XSS 防护（MDX sandbox） |
| 数据备份 | SQLite 文件 + uploads 目录定期备份 |

## 用户流程

```
读者视角：
  首页 → 浏览文章列表 → 标签筛选 → 点击文章 → 阅读正文（TOC导航）
  → 查看评论区 → GitHub 登录 → 发表评论
  → 搜索关键词 → 查看搜索结果 → 点击进入文章

博主视角：
  访问 /admin → 输入密码 → 文章管理列表
  → 新建文章 → ByteMD 编辑器编写 → 上传图片 → 保存草稿/发布
  → 导入 MD 文件 → 自动解析 → 保存到数据库
  → 编辑已有文章 → 修改内容 → 更新
  → 删除文章
```

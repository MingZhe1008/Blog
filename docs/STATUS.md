# 项目当前进度

更新时间：2026-10-29。此文件是后续会话的交接入口，开发规范见 [AGENTS.md](../AGENTS.md)。

## 当前目标

完善个人博客的阅读体验与内容管理，统一博客、层级笔记、摘录和个人项目展示。目前以本地运行验证为主，未确认云服务器部署状态；不能根据 Git 推送推断已经上线。

## 已完成功能

| 模块 | 当前能力 |
|---|---|
| 前台基础 | 动态星空、黑白灰文字、透明卡片、响应式导航、明暗模式、定制鼠标与柔光 |
| 首页 | 个人介绍、GitHub 图标入口、随机读书摘录、透明主题标签；隐藏最近博客区块 |
| 博客 | 文章列表、封面、标签筛选、搜索、分页、MDX 阅读；清理装饰文案和右上箭头 |
| 笔记 | 默认展开的层级目录、标签、内容展示，后台新增和编辑 |
| 摘录管理 | 管理正文、出处和启用状态，首页随机展示 |
| 项目 | 封面、状态、名称简介、技术标签、访问和源码链接；桌面三列、平板两列、手机单列 |
| 项目管理 | SQLite 持久化；新增、编辑、删除，上传/替换/移除封面，草稿与公开开关 |
| 管理台 | 精简导航、当前页高亮、窄屏适配；文章、笔记、项目、摘录、图片、导入入口 |
| 登录和权限 | 表单登录、会话 Cookie、管理台路由保护；文章、图片、项目服务端操作独立鉴权 |

| 国际化 | 本地状态即时切换中英文，保存 Cookie，刷新保持，文档 lang 同步 |
| 主题按钮 | 深色时显示太阳（切换浅色），浅色时显示月亮（切换深色） |
| 启动维护 | start.bat 先构建再启动，开发/生产输出目录分离，sql.js 外部依赖配置 |

## 已知限制与待确认

1. 博客列表封面仍使用 `object-fit: cover`，桌面 240×150、手机 100×90，比例不同会裁切。用户询问过完整展示，但尚未明确要求修改列表；项目封面已使用 contain 完整展示，二者不要混淆。
2. 项目暂不支持排序字段、独立英文内容或项目搜索，这些不是已承诺功能。
3. 本地开发登录带便捷登录行为；对外部署前重新检查生产认证配置。交接文档不记录凭据。
4. 数据库与 uploads 不由 Git 备份；跨机器迁移需单独处理，暂无已验证自动部署、云存储和备份机制。
5. 数据库初始化并发合并仅覆盖单模块实例，不等于支持多进程并发写入；扩展部署前评估 sql.js 持久化方案。
6. Giscus、RSS、性能指标等历史规划未逐项验收；MDX 不是已配置的安全沙箱。
7. 管理台修复只覆盖已发现的问题，不代表所有页面完成系统性排查；新问题记录页面、复现条件和验证结果。

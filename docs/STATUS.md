## 当前目标

完善个人博客的阅读体验与内容管理，统一博客、层级笔记、摘录和个人项目展示。目前以本地运行验证为主，未确认云服务器部署状态；不能根据 Git 推送推断已经上线。

|---|---|

## 已知限制与待确认

1. 博客列表封面仍使用 `object-fit: cover`，桌面 240×150、手机 100×90，比例不同会裁切。用户询问过完整展示，但尚未明确要求修改列表；项目封面已使用 contain 完整展示，二者不要混淆。
2. 项目暂不支持排序字段、独立英文内容或项目搜索，这些不是已承诺功能。
3. 本地开发登录带便捷登录行为；对外部署前重新检查生产认证配置。交接文档不记录凭据。
4. 数据库与 uploads 不由 Git 备份；跨机器迁移需单独处理，暂无已验证自动部署、云存储和备份机制。
5. 数据库初始化并发合并仅覆盖单模块实例，不等于支持多进程并发写入；扩展部署前评估 sql.js 持久化方案。
6. Giscus、RSS、性能指标等历史规划未逐项验收；MDX 不是已配置的安全沙箱。
7. 管理台修复只覆盖已发现的问题，不代表所有页面完成系统性排查；新问题记录页面、复现条件和验证结果。
